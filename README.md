# Body-Explorer 🫀🧠

An interactive Flask website for exploring how the human heart and brain work. Click through each part to see what it does, then test yourself with a quiz.

## Features
- Interactive heart and brain pages with details on each part
- Built-in quiz for both organs
- JSON API for part information (`/api/heart-info/<part>`, `/api/brain-info/<part>`)

## Tech Stack
Python, Flask, HTML, CSS, JavaScript

## Run Locally
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Then open http://localhost:5000
